This is a 10-task, 4-model pilot run to validate the pipeline and price the real sweep. Ten tasks carries a confidence interval of roughly ±30 points on pass@1 — this is not a ranking, and the model ordering below should not be cited.

What it does establish: the collection, pinning, control and scoring path all work end to end, and three findings that will survive to the full run.

What ten tasks already showed

01

Correct is not usable, and the ratio is 4×

gpt-4o-mini passes 40% of tasks and only 10% are usable. A fifth of its patterns are ReDoS-vulnerable; others pass the examples they were given while being provably a different language from the reference. A leaderboard reporting correctness alone would rank this model four times better than it deserves for anything that touches untrusted input.

02

A pinned provider that fails is visible, not substituted

mistral-small-3.2 returned nothing usable across all ten tasks: DeepInfra was rate-limited upstream (engine_overloaded), and because the request set allow_fallbacks: false, OpenRouter refused to quietly reroute to another provider serving different weights at a different quantization.

That is the designed outcome. It is reported as a response-failure rate with the model left in the table, rather than dropped — a visible failure beats an invisible substitution.

03

The wrapper problem — our harness, not their ability

Llama-3.1-8b wrapped five of ten answers in Python raw-string syntax — r'\d+$' where the pattern is \d+$. Scored literally those match nothing, and the model reads as a flat zero.

pass@1 0.0% → pass@1 20.0% — from stripping one layer of quoting

A 20-point swing produced entirely by an extraction rule in our harness, and it penalizes small models hardest. Both scores are published with the count of normalized responses and a before/after record of every strip, because silently picking one rule would bias the board in a direction no reader could detect.

04

Nobody reproduces the reference

exact@1 is 0.0% for every model — not one string-identical answer — and semantic equivalence tops out at 12.5% even where pass@1 reaches 40%. Passing the examples is a far easier problem than reproducing the reference language, which is the case for reporting both.

Controls

Three synthetic predictions ride the identical scoring path in every model's run, because a scorer silently returning zeros looks exactly like a model that failed. All four models' controls came back as expected — including mistral-small, which is how we know its zeros are a collection failure and not a scoring one.
